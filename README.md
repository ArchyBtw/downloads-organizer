# Организатор загрузок

> Сортирует загрузки из директории 'Downloads' по поддиректориям (documents, images, archive...)
> Не трогает скрытые файлы, файлы без расширения и временные файлы браузера

## Требования

> Python 3.12 или новее

## Как запустить

```
python organizer.py
```

## Как работает

> Сначала показывает план, один раз спрашивает подтверждение и потом переносит
> Если имя занято, добавляет номер (book (1).pdf)
